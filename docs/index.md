# Kenswitch Knowledge Hub

A living, plain-English guide to every Kenswitch product — what it does, how it works, what it depends on, how it's regulated, and how it makes money.

This exists because payments infrastructure is extensively wide with tribal knowledge. This hub is for anyone at Kenswitch (or anyone curious) who wants to actually understand the products beyond their own role.

## Start here

- New to Kenswitch? Start with the **[Glossary](glossary/index.md)**.
- Curious about a specific product? Pick one from the **Products** menu above.

## How this hub works

Every product page follows the same structure:

1. **Getting Started** — : what it is, what problem it solves
2. **How It Works** — the actual mechanics, debunked from technical specs
3. **Dependencies** — what it relies on, and what relies on it
4. **Use Cases** — how it's actually applied
5. **Commercials** — how it makes money
6. **Legal & Compliance** — regulatory position, risk allocation
7. **FAQ** — real questions people have actually asked

This hub is collaborative and reviewed with the people who own each product. It's updated as products change whenever something meaningfully shifts. If something's wrong, out of date, or missing, flag it.
